# Business Needs Inventory

**Status:** Draft — collection phase  
**Owner:** TBD  
**Last updated:** 2026-08-27

## Purpose

This document captures what the business needs — operationally, creatively, legally, financially — as we discover it. It's a living list, not a final assessment.

## Structure

Each need gets a row. We fill these in as we learn about the business.

| # | Category | Need | Priority | Status | Notes |
|---|----------|------|----------|--------|-------|
|   |          |      |          |        |       |

## Categories

- **Operations** — delivery logistics, scheduling, client onboarding, equipment management
- **Branding** — name, voice, visual identity, messaging
- **Marketing** — outreach channels, content, clients acquisition
- **Legal/Finance** — pricing, contracts, liability, business structure
- **Systems/Tools** — software, record-keeping, anything that runs the business

## How to use this

- Add rows as needs surface during conversations and document drafting.
- "Priority" is rough: High / Medium / Low.
- "Status" tracks: Identified / Researching / Documenting / Resolved.
