# Enabling the Disabled

Business documentation and operations for a personal training + gym delivery fitness business.

## Layout

```
documents/        # All business documents
  needs-documents/   # Needs assessment, current state, document inventory
branding/         # Brand voice, naming, positioning, creative copy
marketing/        # Marketing plans, content, outreach
operations/       # Operational processes, workflows, delivery logistics
legal-finance/    # Pricing, contracts, legal, finance
```

## Phases

1. **Collect** — gather what exists: documents, facts, constraints, assets.
2. **Assess** — figure out where the business actually stands.
3. **Build** — produce the documents that move it forward.
